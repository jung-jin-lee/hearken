## Web Speech API 텍스트 준비 시 주의사항

웹 브라우저의 `SpeechSynthesis` API 사용 시 음성 자연스러움을 위한 텍스트 정제 포인트:

- **단락 구분**: 너무 긴 문단은 3~5문장 단위로 분리 (한 번에 읽히는 단위)
- **따옴표·괄호**: 한국어 따옴표(`「」`, `『』`)로 통일, 중첩 괄호 제거
- **성경 구절 표기**: "요 3:16" → "요한복음 3장 16절"로 풀어쓰기 (TTS가 자연스럽게 읽음)
- **장·절 제목**: 소제목 앞뒤에 공백 줄 추가 → 자연스러운 쉼 생성
- **숫자**: "17세기" → "십칠세기" 또는 그대로 두되 아라비아 숫자는 문맥에 맞게 처리
- **외래어**: 고유명사(신학 용어, 인명)는 한글 표기로 통일

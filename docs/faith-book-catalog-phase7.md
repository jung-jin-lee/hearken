### 이 카탈로그의 5가지 원칙

1. **Phase 1~6 완전 무중복**

   2026년 기준 저자 사망 70년 이상(1956년 이전 사망). 전량 Gutenberg/CCEL/Archive 소장 확인.

3. **전통 다양성의 균형**
   초대교부(크리소스톰·갑바도기아) → 중세(버나드·힐턴) → 종교개혁(츠빙글리·불링거·틴데일)
   → 아나뱁티스트(메노·후브마이어) → 성공회(테일러·앤드류스·후커) → 감리교(웨슬리·클라크)
   → 근대 변증·선교·교회사 균형 있게 포함.

4. **청각 전달 가능성**
   크리소스톰의 강해, 버나드의 아가서 설교, 바운즈의 기도론 — 모두 음성으로 들을 때
   인쇄 텍스트보다 강렬하게 전달되는 말씀 형식의 텍스트 위주.

5. **한국 교회와의 연관성**

## 선정 기준 및 품질 보증

### 이 카탈로그의 5가지 원칙

1. **한국 신앙 전통과의 연관성 우선**
   한국 장로교(프린스턴 신학, 투레틴, 브라켈), 한국 성결교(경건주의), 한국 침례교(풀러)의 직접적 사상적 원천에 집중.

2. **영향력 기준 — 신학자들이 신학자들에게 준 영향**
   "이 책을 읽지 않고서는 X를 이해할 수 없다"는 책들만 포함.
   예: 투레틴 없이 프린스턴 신학 이해 불가, 브라켈 없이 네덜란드 개혁교회 이해 불가.

3. **접근성 — 청각으로 전달 가능한 내용**
   고도로 기술적인 철학 논증보다 설교·서신·전기·묵상 형식의 텍스트 우선.
   주석류는 짧은 묵상 단위로 분할 가능한 것만 포함.

4. **퍼블릭 도메인 확실성**
   최종 사망 연도 1935년 이전. 모든 텍스트 Gutenberg/CCEL/Archive에서 영문 원문 확보 가능.

5. **기존 카탈로그 완전 무중복**
   Phase 1~5에 포함된 저자·제목 목록을 전수 확인 후 배제.
